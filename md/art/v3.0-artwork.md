# v3.0 原创战争沙盘资源

2026-10-22。四份资源由内置 imagegen 生成，用于真实可操作的 SwiftUI 游戏，不是整屏 UI 效果图。没有使用 EasyTech 截图、贴图、商标、名将肖像或第三方素材；没有 CLI/API key 路径、图片后处理脚本、网络运行时或第三方库。参考只用于观察《将军的荣耀3》的地图/兵模层次。

## 存放与使用

- `WW2Tactics/WW2Tactics/BattlefieldArt/vehicles.png`：1536×1024，透明 2×2 atlas；第一行盟/轴坦克，第二行盟/轴轮式侦察车。
- `WW2Tactics/WW2Tactics/BattlefieldArt/troops.png`：1536×1024，透明 2×2 atlas；第一行盟/轴三人步兵，第二行盟/轴火炮。
- `WW2Tactics/WW2Tactics/BattlefieldArt/scenery.png`：1536×1024，透明 2×2 atlas；按行是针叶林、岩石山脊、村镇、雪林。
- `WW2Tactics/WW2Tactics/BattlefieldArt/ground.png`：正方形草土底材。确切尺寸、字节数与 SHA-256 见 `v3.0-artwork.json`。

每格固定 768×512；原生 ImageIO 一次解码，CGImage 按象限裁格后静态复用，无离线裁图或修改原 PNG。总计约 11.3 MiB，资源门禁上限 24,000,000 bytes。Xcode Resources 显式复制整个 BattlefieldArt 文件夹；缺失、白底、空 sprite、错误尺寸会被云端 XCTest 捕获。通用兵种模型不宣称逐个还原单位名称中的全部历史装备型号。

生成后只做原图目视、文件元数据与 alpha 像素读取，并复制原文件；没有本地项目测试、构建、模拟器或 app 截图。游戏实际集成、所有资源门禁与最终视觉证据由云端验证。内置工具生成的源图保留在 Codex generated_images；项目只依赖本仓库的四个最终 PNG。
