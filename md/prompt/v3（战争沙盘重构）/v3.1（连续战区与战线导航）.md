## 目标

1. 默认镜头从后方空地转向真实双方接触前线；不改变初始单位、选择、焦点、行动、资源或战役规则。保留主动焦点与交战中点定位。
2. 提供小型战区总览与“返回前线”入口：总览从真实地格/单位/据点派生，点按只调用 GameState 的 focus；不执行命令，不伪造镜头框。宽屏默认可见，窄屏可展开/收起。
3. 雪地由硬亮逐格白片改为连续、低对比、有机积雪；河道保留真实 river 邻接，使用确定性共享端点、连续切线和变化河岸宽度，消除均匀管道观感。
4. 放大并错落地貌簇，减少重复图章/空地观感；保留六角战术结构、离线原创资源、兵模与所有状态可读。
5. 情报按钮归入右上地图工具组，面板内有明确关闭按钮，不再悬在交战区中央。窄屏工具和底部命令不溢出。
6. 原 5,044 行 Inspector 按单位、规划、态势、战果、敌情、回放、图例拆分；战役栏和动作坞独立。原 80 个顶层声明保持完整，只有必要共享访问级别改变，不删除原面板或入口。

## 非目标与架构依据

不改 GameState / GameModels 的规则、AI、伤害、寻路、补给、胜负或战役数据；不新建镜像状态机。不新增战役、海空军、存档、3D 引擎、网络、依赖、美术下载或新生成资源。

ContentView 只做根编排与情报展开；CommandDeck 管动作入口；Navigation 管小型地图与纯表现投影；TerrainGeometry 管纯只读河岸几何；TerrainRenderer 管 Canvas；HexMapView 共用既有 layout / 输入 / combat 链。新文件加入现有 Xcode Sources phase，不整体迁移观察框架。

## 验收标准

默认两端能看到真实双方战线和足够地图，不再只有后方空地；可读精细军械、地貌和六角战术层；小地图与“前线”入口只定位；情报可关且不常驻交火中心；雪地连续而非亮白拼片，河岸变化且邻格不裂开。HIT/RET、命令、HP、M/A、AL/AX、目标、支援与轨道保留。五阶段与全部实际用例成功、四图逐张查看后才能宣称本轮通过。

## 风险与禁止项

缩略地图不等于视口跟踪；默认前线镜头不代表规则初始焦点改变。河岸允许小幅视觉外溢，但不能改变可渡河地格或路线。雪原柔化不能隐藏道路/河道/单位或战术提示。四图不证明横屏/触屏/VoiceOver/全部 Dynamic Type 实测。禁止伪造伤害、改断言求通过、沿用旧 artifact、下载官方资产、删除用户改动、reset/amend。相同原因 CI 连续失败或其他 AGENTS 停止条件出现时停止盲推并交还人工决定。
