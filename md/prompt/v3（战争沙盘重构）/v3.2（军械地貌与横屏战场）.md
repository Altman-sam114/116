## 目标、非目标与架构

1. 新增 M10/M7/Tiger/Panther 原创透明模型，M10 不再显示为轮式车；模型选择只读 unit 名称、阵营和 kind，绝不改变 recon / artillery 规则。
2. 林地有不同剪影、疏密和树种；低频草土/田块/雪原形成连续地表。城镇接真实道路，只有真实相对两岸道路才画桥；不暗改通行和河流成本。
3. 使用当前共享六角投影和静态 Canvas；河流穿过两侧 river 夹住的 city/road 时保持连续，端头有自然水潭；不在 plains/mountain 中凭空接河。
4. 短屏横向视口使用紧凑顶栏/动作坞，不能因为宽度大而默认展开总览挡住整片战场。隐藏非游戏状态栏，保留所有地图规则和情报入口。
5. 云端保留原四张竖屏，新增两设备真实横屏战果图；DEBUG 参数仅经公开 scene geometry API 请求横屏，不旋转像素或伪造尺寸。Vision 识别上方 Apple Intelligence 通知，命中时继续有界重拍，绝不修图移除遮挡。

非目标：不增加战役、存档、海军、经济系统、网络依赖或实时 3D；不重写 GameState / GameModels / AI / 路线 / 伤害；不重做无关 Inspector 业务。既有未跟踪 v2.56 文件不修改、不提交。
