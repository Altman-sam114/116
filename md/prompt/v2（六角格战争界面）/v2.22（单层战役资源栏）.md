# v2.22 单层战役资源栏

## 版本号与分配依据

- 版本号：`v2.22`
- 分配依据：v2.21 已由 `origin/main` commit `732798528e12deda4bf230efaf155bf8dfe5fd73`、GitHub Actions run `30195217772`、attempt `1` 和 artifact `ww2tactics-ci-v2.21-main-7327985-run30195217772-attempt1` 完成云端验收。其截图确认地图外通讯行已回收，但顶部双行战役标题、六个长标签胶囊和系统圆形结束按钮仍占据较多视觉重量，因此递增 v2 小版本收敛顶部资源栏。

## 背景

EasyTech《Glory of Generals 3》的战场界面使用薄资源栏承载回合、阵营与资源，让地图、地貌和兵模保持首要地位。当前 `TopCommandBar` 虽在一个 HStack 内，但内部标题仍为两行，状态项重复显示长中文标签，`.borderedProminent` 的结束回合按钮呈现为醒目的大圆形，整体更像应用工具栏而非战场指挥条。

## 目标

1. 将战役身份压为 `WW2 / 战役名 / 年份` 单行，并保留完整 VoiceOver。
2. 将回合、剩余、阵营、据点、指令点、待命单位压成图标与短值，完整语义交给 accessibility label/value。
3. 将结束回合改为稳定 44x44pt 的战场方形命令键，继续只调用 `game.endTurn()`。
4. 保持战役菜单、状态横滚、禁用逻辑、地图高度与全部规则入口不变。
5. 云端截图确认顶栏更薄、更安静，且 v2.21 的通讯坞、HIT/RET、动作坞和 AL/OBJ/AX 均无回归。

## 非目标

- 不修改 `GameState.swift`、`GameModels.swift`、战役数据、规则、回合推进、分数或可用单位计算。
- 不修改地图 frame、缩放、手势、命中、marker、动作坞、通讯坞、定位轨道或支援甲板。
- 不修改 workflow、CI 参数、Xcode project，不引入第三方库、资产或网络依赖。
- 不触碰、暂存或提交用户已有的 `AGENT.md` 删除、`project.pbxproj`、`update_log.md` 和 `md/unity分析/`。

## 当前架构依据

- `TopCommandBar`、`CommandTitle`、`StatusStrip`、`StatusChip` 和 `EndTurnButton` 均位于 `BattlefieldChrome.swift`，只读既有 `GameState` 并转发命令。
- `Faction.shortTitle` 已提供 `AL/AX` 紧凑阵营码，不需要新增模型字段。
- `ScrollView(.horizontal)` 已承担窄宽度溢出，短值只改善密度，不删减任何资源项。
- `game.endTurn()` 与 `winner` 禁用条件是既有状态边界，本轮保持原样。

## 实现步骤

1. 将 `CommandTitle` 的 VStack 改成稳定单行 HStack，名称和年份不换行，组合朗读完整战役信息。
2. 将 `StatusChip` 参数拆成 `icon/value/label`；可视层只显示图标和值，无障碍层读出完整标签和值。
3. 六项状态分别使用短值：回合数、剩余回合、`AL/AX`、双方据点比、指令点、待命数。
4. 移除 `EndTurnButton.iconOnly` 分支和 `.borderedProminent`，使用 `.plain`、44x44 固定方形背景、明确 label/hint 与原禁用条件。
5. 同步 README、flow、flowchart、test 和 prompt README；`update_log.md` 因用户未提交内容保持不动。

## 验收标准

1. 战役身份在顶栏中保持单行，VoiceOver 完整读出 WW2、战役名和年份。
2. 六项状态同时存在，只显示图标与短值；每项均提供完整 label/value，颜色不是唯一编码。
3. 状态区继续横向滚动，不使用 `prefix`、分页或缓存删减项目。
4. 结束回合为 44x44pt 圆角方形 `.plain` Button，只调用 `game.endTurn()`，胜负后禁用。
5. `GameState`、地图输入、通讯坞、动作坞、AL/OBJ/AX 和支援甲板不变。
6. 云端 PNG 顶栏视觉高度和信息噪音低于 v2.21，地图与兵模仍是主体，且 HIT/RET、“交火”和三段定位轨道完整。
7. 最新 `origin/main`、workflow run 与 artifact manifest 的 branch/SHA/run/attempt 完全匹配，全部配置检查成功。

## 风险和禁止项

- 禁止为追求紧凑删掉状态项、缩小交互热区、截断无障碍语义或用颜色代替阵营码。
- 禁止在 View 中重算回合、分数、指令点或待命单位。
- 禁止改变 `game.endTurn()`、战役切换、横向滚动或 winner 禁用语义。
- 禁止修改 CI 门禁、使用本地截图冒充云端证据，或提交用户未提交文件。
