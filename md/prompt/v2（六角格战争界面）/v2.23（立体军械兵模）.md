# v2.23 立体军械兵模

## 版本号与分配依据

- 版本号：`v2.23`
- 分配依据：v2.22 已由 `origin/main` commit `19a2b1d2f8db47bad00da68160b298983083b31f`、GitHub Actions run `30196193072`、attempt `1` 和 artifact `ww2tactics-ci-v2.22-main-19a2b1d-run30196193072-attempt1` 完成云端验收。官方《Glory of Generals 3》截图强调大比例实体兵模、车体明暗面、结构细节、地面阵营环和下置状态；当前地面环与状态已稳定，但军械主体仍以单层矢量剪影为主，因此递增 v2 小版本专门提升地图兵模。

## 背景

官方 Google Play 截图显示，坦克、火炮、步兵队和侦察车辆都以清晰侧向造型占据六角格视觉中心，炮塔、履带、车体、炮架和士兵队形无需文字即可辨认。当前 `UnitModelView` 已有四类轮廓和阵营渐变，但主轮廓、结构线和阴影基本处于同一平面，远看容易退化成深色图标。v2.23 应在不引入外部资产管线的前提下，建立更接近实体军械插画的分层材质。

## 目标

1. 为四类单位建立暗色厚度层、阵营主材质、军种装备面、结构线和顶缘高光五层模型。
2. 坦克突出履带、车体、炮塔和炮管；火炮突出车轮、炮盾、炮架和身管；步兵突出三人队形、钢盔和武器轴线；侦察车突出轮组、车舱、引擎盖和天线。
3. 适度放大地图模型，让军械成为地格第一视觉信号，同时不改变 tile frame、命中、zIndex 或滚动范围。
4. 保留阵营地面环、AL/AX、军衔、将领、CUT、战术状态、五段 HP 和移动/攻击状态。
5. spent 仍只在移动与攻击均消耗后整体降权，新增材质层必须同步降权。

## 非目标

- 不修改 `GameState.swift`、`GameModels.swift`、单位数值、兵种规则、移动、攻击、AI 或战役数据。
- 不修改 `BattlefieldMap.swift` 的 tile frame、坐标、手势、命中、marker、控制区或交战叠层。
- 不引入图片、3D、SpriteKit、第三方库、网络依赖或复杂资产管线。
- 不重构非地图 `UnitShapeBadge` 的容器语义，不修改 workflow、CI 参数或 Xcode project。
- 不触碰、暂存或提交用户已有的 `AGENT.md` 删除、`project.pbxproj`、`update_log.md` 和 `md/unity分析/`。

## 当前架构依据

- `UnitCounter` 继续负责模型与行动状态轨道，`MapUnitPiece` 继续负责地面环和状态角标。
- `UnitModelView` 已从 `UnitKind`、`Faction`、`isSpent` 只读派生模型，是增加纯表现层次的唯一入口。
- `UnitMarkerShape` 和 `UnitModelDetailShape` 已提供轮廓与结构线；新增 plate/highlight Shape 只补充表现，不新增状态。
- `HexTileView` 的 tile frame、contentShape、输入与 sibling zIndex 已由此前版本验证，本轮保持无 diff。

## 实现步骤

1. 在 `UnitModelView` 主轮廓下增加暗色偏移厚度层，并加强模型落地阴影。
2. 新增 `UnitModelPlateShape`，按军种绘制钢盔/胸甲、炮塔/首上甲板、炮盾/炮闩、车舱/引擎盖等装备面。
3. 新增 `UnitModelHighlightShape`，为炮管、装甲顶缘、钢盔和车辆结构提供细窄高光。
4. 扩展阵营材质色：depth、plate、highlight；所有颜色跟随 spent opacity，不改变阵营地面环编码。
5. 将地图模型高度从 40pt 调整为 44pt，四类 mapPieceWidth 各增加 6pt；状态轨道尺寸保持不变。
6. 新增 Shape 与装饰层全部位于既有 `accessibilityHidden(true)` 模型树中，UnitCounter 继续只暴露原完整组合摘要。
7. 同步 README、flow、flowchart、test 和 prompt README；`update_log.md` 因用户未提交内容保持不动。

## 验收标准

1. 四类模型无需依赖文字即可通过轮廓、装备面和结构线区分。
2. 坦克、火炮、步兵、侦察车均显示暗色厚度、主材质、装备面、结构线与高光，不出现纯色扁平剪影。
3. 模型比 v2.22 更大，但不遮挡 HP、移动/攻击状态、阵营码、军衔、将领和战果层。
4. 盟军与轴心在模型材质、地面环颜色及实/虚线编码上继续可区分，颜色不是唯一编码。
5. completed 单位的所有新层同步降权，单独移动或攻击不降权。
6. `BattlefieldMap.swift`、`GameState.swift`、`GameModels.swift`、workflow 和 Xcode project 无本轮 diff。
7. 云端 PNG 保留真实 HIT/RET、“交火”、动作坞和 AL/OBJ/AX，同时模型体积与结构清晰度高于 v2.22。
8. 最新 `origin/main`、workflow run 与 artifact manifest 的 branch/SHA/run/attempt 完全匹配，全部配置检查成功。

## 风险和禁止项

- 禁止让放大模型改变地格布局、contentShape、命中范围或遮挡相邻单位的状态轨道。
- 禁止复制兵种规则、用 View 状态保存模型类型或根据单位名称猜测造型。
- 禁止让装饰层进入 VoiceOver 树，或让颜色成为唯一军种/阵营编码。
- 禁止降低截图门禁、使用本地截图冒充云端证据，或提交用户未提交文件。
