# v2.35 选中兵棋实体焦点

## 版本号与分配依据

- 版本号：`v2.35`
- 分配依据：v2.34 修复 commit `cec4ecc102ae3608d4810b3109e17d0b254366dd` 已由 run `30322225981`、attempt `1`、artifact `ww2tactics-ci-v2.34-main-cec4ecc-run30322225981-attempt1` 完成云端结构和截图实看验收。当前选中单位同时使用黄色粗六角边、青色地环和蓝色四角框，语义混杂且容易与盟军蓝色阵营环混淆，因此递增小版本统一实体选中焦点。

## 背景与目标

EasyTech 风格以实体兵棋本身承载主要选择反馈。当前战场已经完成标记降噪，但选中态仍由三种颜色重复表达，steady combat 截图里攻击方不够突出。本轮统一为暖金/象牙地环、细六角辅助边和同色四角框，并将选中棋子静态上抬 3pt、补充接地阴影，形成“拿起待命令”的物理层级。

## 非目标

- 不修改 `GameState`、`GameModels`、选择/移动/攻击规则或战役数据。
- 不修改 tile frame、contentShape、手势、坐标、缩放、zIndex 或滚动范围。
- 不修改 v2.34 战果铭牌、phase、HUD、AL/OBJ/AX、地貌或军械路径。
- 不新增动画、图片、第三方库、网络依赖或资产管线。

## 架构依据与实现步骤

1. 在 `BattlefieldTheme` 增加共享暖金选中 token。
2. `HexTileView` 的 selected border 和 reticle 统一读取该 token，选中边从 3pt 降为 1.5pt。
3. `SelectedUnitGroundHalo` 改为象牙中心、暖金外沿、暗色接地边的径向实体底座。

5. 同步 README、flow、flowchart、test、prompt README 和 update_log。
