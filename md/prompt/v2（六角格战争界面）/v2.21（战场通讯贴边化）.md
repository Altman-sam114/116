# v2.21 战场通讯贴边化

## 版本号与分配依据

- 版本号：`v2.21`
- 分配依据：v2.20 已由 `origin/main` commit `ced94b1bbf1b7e1acf16af481217100d9faff65b`、GitHub Actions run `30194360827`、attempt `1` 和 artifact `ww2tactics-ci-v2.20-main-ced94b1-run30194360827-attempt1` 完成云端核对。manifest 的 branch/SHA/run/attempt 完全匹配，static、RulesSmokeTest、build-for-testing 与 screenshot 均成功，JUnit 4 项 0 failures；2064x2752 PNG 为 5,987,823 bytes。v2.20 已让 AL/OBJ/AX 同屏，但地图上方仍有一整行战场消息和独立重开按钮，持续占用地图高度，因此递增 v2 小版本只收敛这条地图外 chrome。

## 背景

EasyTech《Glory of Generals 3》官方截图把即时战场信息和命令压在地图边缘，核心视野始终交给地形与兵模。当前 `BattlefieldView` 在 `MapCommandCenter` 上方固定放置消息条和 44pt 重开按钮；即使消息只有一行，该 HStack 仍永久压缩六角地图。v2.21 应把消息变成地图左上缘的轻量只读通讯坞，并把重开入口并入现有地图工具栏。

## 目标

1. 删除 `BattlefieldView` 中地图外的消息/重开整行，让 `MapCommandCenter` 直接占据其可用高度。
2. 在地图 overlay 左上显示稳定 44pt 高的战场通讯坞，继续完整读取 `game.message`，不拦截地图输入。
3. 通讯坞与右上 `MapActionHUD` / `MapIdleCommandDock` 同处一行且有明确宽度约束；regular 和 compact 均不得重叠。
4. 把重开按钮并入 `MapToolbar`，保持至少 44x44pt、现有 `game.restart()` 行为和完整 VoiceOver。
5. 保留地图工具栏、缩放、右上动作坞、底部 AL/OBJ/AX、支援甲板和全部 GameState 行为。
6. 云端截图应比 v2.20 多露出一条横向战场区域，同时保留完整战果、单位状态和三段定位轨道。

## 非目标

- 不修改 `GameState.swift`、`GameModels.swift`、战斗、移动、AI、胜负、消息生成或重开规则。
- 不修改 `BattlefieldMap.swift`、地图 frame 算法、缩放值、坐标、marker、手势或命中链。
- 不修改 `MapActionHUD`、`ObjectiveJumpDock`、支援甲板展开内容、workflow、CI 参数或 Xcode project。
- 不新增自动消退、toast 队列、分页、计时器、第三方库、网络依赖或资产管线。
- 不触碰、暂存或提交用户已有的 `AGENT.md` 删除、`project.pbxproj`、`update_log.md` 和 `md/unity分析/`。

## 当前架构依据

- `BattlefieldView` 只负责地图外布局，本轮删除其冗余 HStack，不改变状态来源。
- `game.message` 是既有战场通讯单一数据源；新通讯坞只读该值。
- `MapCommandCenter` 已拥有地图 overlay 左上/右上的布局入口，可让通讯坞与动作坞共享一行。
- `MapToolbar` 已承载地图标题与缩放选择，适合容纳全局但低频的重开命令。
- `game.restart()` 是现有唯一重开入口；View 只能转发 action。

## 实现步骤

1. 删除 `BattlefieldView` 中消息 Label 与重开 Button 组成的顶层 HStack。
2. 新增轻量 `BattlefieldMessageDock`，固定 regular/compact 宽度、最小高度 44pt、单行截断；VoiceOver 继续读取完整消息。
3. 通讯坞使用 `allowsHitTesting(false)`，不得遮断底层地图拖拽、格子点选或右键操作。
4. 在 `MapCommandCenter` 顶部 overlay HStack 左侧放通讯坞，右侧保留现有动作坞或空闲 NEXT 坞；通过稳定宽度和 Spacer 防止二者碰撞。
5. 新增 `MapRestartButton`，并入 `MapToolbar` 的缩放控件右侧；保持 44x44pt、plain 战场样式、`game.restart()` 与“重新开始”无障碍标签。
6. 适度收紧 toolbar 垂直 padding，使新增按钮不反向增加固定 chrome 高度。
7. 同步 README、flow、flowchart、test 与 prompt README；`update_log.md` 因用户未提交内容保持不动。
