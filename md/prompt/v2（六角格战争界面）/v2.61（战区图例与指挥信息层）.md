# v2.61（战区图例与指挥信息层）

## 版本分配依据

v2.60 已完成云端构建成功；本轮继续六角战区表现层迭代。

## 背景与目标

《将军的荣耀3》式地图需要快速读出盟军、轴心和据点身份。本轮在制图层增加轻量 AL/AX/OBJ 图例，让颜色、缩写和地图对象建立稳定对应，同时保持地图主体和单位模型的视觉优先级。

## 非目标

不修改规则、GameState、GameModels、输入、六角几何、单位数据、命令 action、测试逻辑或外部资源。

## 实现

`HexMapView` 只读渲染 `MapBattleLegend`，图例位于制图背景层，关闭命中和无障碍；图例使用现有阵营与 War Ledger 颜色 token。

## 云端验收

不运行本地 Swift/Xcode；提交 `v2.61: ...` 到 `main`，由 GitHub Actions 执行 static、Rules smoke、Xcode build-for-testing 和 screenshot。Agent C 下载 exact artifact，核对 manifest commitSha、runId、runAttempt 与截图。
