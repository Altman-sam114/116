# v2.62（云端截图超时保护）

## 版本分配依据

v2.61 已完成 UI 图例改动；云端构建通过但截图步骤长时间等待。本轮是同一阶段的 CI 稳定性修复。

## 目标

为 GitHub Actions 的模拟器启动、安装和启动命令增加有限超时，避免截图阶段无限等待，使云端失败能生成 manifest 和 failure summary。

## 非目标

不修改 SwiftUI、GameState、规则、地图几何、模拟器选择策略或本地环境。

## 实现

`.github/workflows/ci-results.yml` 对 `simctl bootstatus`、`simctl install`、`simctl launch` 分别增加 180s、120s、60s timeout；后续状态汇总链保持执行。

## 验收

只执行 `git diff --check`；推送 main 后由 Actions 运行静态检查、Rules smoke、Xcode build、截图和 artifact。Agent C 核对最新 manifest 与 artifact。
