# v2.63（云端构建超时保护）

## 版本分配依据

v2.62 的云端截图超时保护已推送，但同一 run 在 `Run checks and build` 长时间无终态。本轮继续 CI 稳定性修复。

## 目标

为规则 smoke 的 Swift 编译和 Xcode build-for-testing 增加显式超时，确保卡住时仍能进入截图、结果元数据和 artifact 上传步骤。

## 实现

`.github/workflows/ci-results.yml`：swiftc 300 秒、xcodebuild 900 秒；保留原有状态码汇总和后续 artifact 流程。

## 非目标

不修改 SwiftUI、GameState、地图、单位、规则或模拟器选择。

## 验收

只运行 `git diff --check`；推送 main 后由 Actions 完成云端验证，Agent C 核对 manifest、日志、JUnit、构建结果和截图。
