## 2. 背景

WW2Tactics 当前是 22×14 Arden 战区的 SwiftUI 六角战棋界面，表现层已经具备道路、河流、地形纹理、单位棋子、据点地标、控制标识、战斗反馈、顶部状态栏和 `AL / OBJ / AX` 目标轨。近期迭代已经完成：

- v2.50：共享边、地形过渡和地图边缘的蚀刻边界分层；
- v2.51：道路材质层收敛；
- v2.52：平原/雪地连续性弱缝；
- v2.53：威胁、控制区、补给和状态边缘的重复粗描边去重；
- v2.54：普通据点不再因为 `tile.isObjective` 获得长期整格粗轮廓，同时保留据点地标、旗牌、名称牌、owner fill 和局部高优先级状态。

当前 regular 云端截图中，地图底色仍是最影响“精致战争地图”观感的问题：每个六角格直接使用高不透明度的独立 `mapGradient`，平原和雪地尤其容易形成明暗突兀、近似贴纸拼块的色块。雪地区域看起来偏白且被格子切碎，地图底层不像一张连续的战区地表；但森林、山地、道路、河流、单位和交战提示已经承担了足够的识别信息，不应靠新增装饰覆盖它们。

本轮以官方参考图目录 `/private/tmp/easytech-gog3-ref-YqthSi/` 中的连续浅色雪地和低对比大地图观感为方向，仅调整现有地图底色的表现方式，不复制或引入任何外部图片或资产。上一轮 regular PNG `/private/tmp/ww2tactics-c-review-32650699536/battlefield-screenshot.png` 只能作为视觉对照，不能作为本轮云端证据。

## 3. 本轮具体目标

### 3.1 主目标

在 `BattlefieldMap.swift` 的纯视图层中，收敛六角格最底层的地貌填充对比，使地图底色更像连续的战区地表：

1. 降低平原、雪地以及相邻同类地形之间过强的独立色块感；
2. 让现有 `MapGridBackdrop`/地图底层在六角格之间提供更连续的基底，避免一格一块的高亮白色或高饱和色块；
3. 保留现有地形身份：森林树木、山地纹理、道路、河流、地形连接和蚀刻边界仍应清楚可读；
4. 保留所有高优先级战术反馈：选中金边、攻击/战斗回应边、行动/路线/压制/补给提示、据点地标和单位信息不被底色调整冲淡；
5. 让变化能在标准 regular 云端 battlefield screenshot 中直接观察到，而不是只在未覆盖的极端缩放或理论状态中成立。

### 3.2 推荐实现边界

优先只改 `HexTileView` 现有地貌基础填充，也就是 `Hexagon().fill(tile.terrain.mapGradient)` 所在的最底层。可以在同一 `BattlefieldMap.swift` 内增加一个无状态、纯计算的地图底色辅助值，使用单一受控 opacity；如 regular 截图证明雪地仍明显过亮，最多采用“雪地与其他地形”两组固定常量。具体常量由 Agent B 依据现有 token 和云端截图调节，但必须满足：

- 只作用于最底层地貌 fill；
- 不改变 `TerrainKind.mapGradient`、`mapColor`、`mapHighlight`、`mapShadow` 的既有定义；
- 不把整个 `HexTileView` 或其所有 overlay 统一降 opacity；
- 不新增邻接计算、全图覆盖层、路径、渐变缓存、动画或随机视觉；
- 优先复用已有 `MapGridBackdrop`、`BattlefieldTheme` 和地形纹理，不增加新的颜色系统或资产。

v2.52 已经处理了 plains/snow continuity stroke，本轮不是重新绘制接缝，也不是修改 `HexEtchedBoundaryLayer`；本轮只处理边界下方的 base fill 视觉重量。

## 10. 风险与处理

- **底色过淡**：若所有地形都失去识别度，优先在基础 fill 的固定 opacity 内小幅回调；不能把森林/山地纹理、单位或战术 overlay 一并加深来补偿。
- **雪地仍过亮**：可在同一纯视觉 helper 内对雪地做有限静态分组；不能改 `GameModels` 或全局 `TerrainKind` 规则，也不能重新绘制 snow continuity。
- **底层透明后暴露意外底色**：检查现有 `MapGridBackdrop` 与基础 fill 的叠加关系，但不得新增 map geometry、全屏遮罩或资产；保持 map canvas 尺寸与背景链路不变。
