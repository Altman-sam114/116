# v2.60（战区制图层与将军的荣耀风格）

## 版本分配依据

当前 origin/main 最新已验收版本为 v2.59；本轮继续 v2 六角格战争界面阶段。

## 背景与目标

百度图片“将军的荣耀3”可见的核心风格是低饱和地形、清晰六角边界、军棋单位集中在地图上、顶部战役信息克制且有地图制图感。本轮在现有 War Ledger 基础上补充轻量制图标记与比例尺，让地图更像可读的战区桌面。

## 非目标

不改变 GameState、GameModels、AI、战斗公式、移动/攻击命令、六角几何、输入区域、第三方资源或网络依赖。

## 架构依据与实现步骤

1. `HexMapView` 继续只读既有地图尺寸，在地图背景层加入无命中、无障碍的 `MapCartographyStamp`。
2. 标记包含北向、比例尺和六角公里说明，置于地貌下层，不遮挡单位和战术反馈。
3. 由 GitHub Actions 负责 smoke、Xcode build-for-testing 和截图；本地不运行 Swift/Xcode/模拟器。
