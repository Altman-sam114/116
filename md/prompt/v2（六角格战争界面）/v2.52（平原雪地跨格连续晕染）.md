## 背景

v2.43 已在 `TerrainTexture.terrainContinuityLayer(_:)` 中复用既有同类邻接方向和 `connectionPath(in:)`，为森林与山地添加跨格连续阴影；v2.48 又把平原 `fieldLines(in:)` 收为 1-2 个低对比块面，把雪地 `snowDrifts(in:)` 收为漂移曲线与低密度针叶树。当前源码中 `.forest`、`.mountain` 已消费 continuity path，而 `.plains`、`.snow` 仍在 `terrainContinuityLayer` 返回 `EmptyView()`。

因此，大片平原仍容易被各格独立块面和 v2.50 蚀刻边切成逐格贴片；亮白雪地区域尤其容易显出六角拼接节奏。这个问题属于已有静态地貌连续层的两个缺口，不需要修改格内纹理、六角边界、全局底材、地图几何或任何规则事实。

本轮唯一主题是：**为平原与雪地补上极弱、低频、宽幅的跨格连续晕染**。实现必须沿用现有 `terrainConnectionDirections -> connectionPath -> terrainContinuityLayer` 模式，让同类区域更像连续地表，同时避免生成可被误认成道路、河流、补给线、路线或边界光晕的线性信号。

## 目标

1. 在 v2.52 regular 战场截图中，大片平原和亮白雪地的逐格切片感降低，同类相邻格优先读作柔和连续区域。
2. `.plains` 与 `.snow` 只使用既有 `terrainConnectionDirections` 和同一个 `connectionPath(in:)`，各增加一次极弱、低频、宽幅的静态 continuity stroke/wash；不得创建新方向、新边集合、新 Path 或新 overlay 网络。
3. 平原晕染贴近既有暖纸张/低饱和田野色相，雪地晕染贴近既有极浅冷灰/雪面阴影；二者都必须弱到看不出清晰中心线，只形成跨共享边延续的宽幅色面。
4. 保持现有 `fieldLines(in:)` 的块面数量、位置、角度、颜色和 seed 逻辑不变；保持 `snowDrifts(in:)` 的漂移曲线、highlight、针叶树数量/位置/形状和 seed 逻辑不变。
5. 保持森林、山地现有 continuity stroke 原样；城市、河流、道路的 continuity/connection 分支原样；v2.50 `HexEtchedBoundaryLayer` 原样。
6. 所有新增表现继续继承 `TerrainTexture` 的 tile-local `Hexagon` clip、`allowsHitTesting(false)` 和 `accessibilityHidden(true)`，不新增状态、缓存、动画、资源或 VoiceOver 节点。

## 架构依据

- `HexMapView` 已对非道路地形从 `tile.coordinate.neighbors` 只读派生同类 `terrainConnectionDirections`；平原与雪地已经收到这组方向。本轮无需也禁止新增邻接计算、地图缓存或连通图。
- `HexTileView` 把同一组方向传给 `TerrainTexture`。`TerrainTexture.connectionLayer(in:)` 先用 `connectionPath(in:)` 构造中心到同类邻接边的既有 Path，再调用 `terrainContinuityLayer(_:)`，之后才绘制 `fieldLines(in:)` 或 `snowDrifts(in:)`。因此正确开口仅是 continuity switch 的 `.plains` 与 `.snow` 分支。
- `terrainContinuityLayer(_:)` 目前对 `.forest` 使用 `mapForestContinuity` 宽 stroke，对 `.mountain` 使用 `mapMountainContinuity` 宽 stroke，其余地形为 `EmptyView()`。v2.52 应复用这一单 stroke、round line cap/join、tile-local clip 模式，不抽取新网络、不改 Path 几何。
- `BattlefieldTheme.swift` 集中保存 map-only 静态 token。本轮如需独立控制颜色/透明度，最多新增两个语义 token，例如 `mapPlainsContinuity` 与 `mapSnowContinuity`，且只能由上述两个 continuity 分支消费；不得修改任何既有 token。
- `TerrainTexture` 外层已统一 `.clipShape(Hexagon())`、`.allowsHitTesting(false)`、`.accessibilityHidden(true)`。新增 stroke 只继承这条纯装饰边界，不建立新可访问节点或命中区域。

## 数据与表现流

```text
TerrainTile(.plains / .snow) + existing same-terrain neighbors
  -> unchanged terrainConnectionDirections
  -> unchanged connectionPath(in:) / endpoint(for:in:)
  -> terrainContinuityLayer 单次宽幅极弱 stroke
  -> unchanged fieldLines / snowDrifts + conifers
  -> unchanged HexEtchedBoundaryLayer / road / river / objective / unit / marker / combat / HUD / rail
  -> existing Hexagon clip + non-hit-testable + accessibilityHidden
```

不得向 `TerrainTile`、`GameState`、`GameModels` 或任何规则状态写回内容；不得缓存 path、复制邻接数据或新增 `@State`、`@Published`、timer、动画、随机材质。

## 风险与禁止项

- 最大风险是宽 stroke 仍被看成从六角中心向外放射的线，或在共享边处形成可读 halo。必须用极低对比、单笔、round cap/join 和足够宽的色面降低线性；不得用更多笔画、blur、offset、虚线或边框补救。
- 平原 token 过暖/过饱和会形成黄褐道路，雪地 token 过蓝/过暗会形成冰河或阴影管线；优先降低 opacity，而不是修改全局地貌色或增加高光。
- 晕染过强会覆盖 `fieldLines`、`snowDrifts`、据点和单位，过弱则无法降低拼片感；取舍只允许调两个新 token 与两个 continuity stroke 的宽度，不得修改局部纹理、边界或高优先级叠层。
- 禁止条纹、lattice、管线、假道路、假河流、补给通道、中心节点、格边 halo、全局 wash、厚阴影、发光、blur、动画或随机噪声。
- 禁止删除、回滚、覆盖用户或其他 Agent 改动；工作树若有无法判断归属的改动，停止并报告。
- 禁止使用 v2.51 或更早 artifact、旧 PNG、本地输出或 checkout 自带报告冒充 v2.52 证据；云端闭环前不得宣称通过。
