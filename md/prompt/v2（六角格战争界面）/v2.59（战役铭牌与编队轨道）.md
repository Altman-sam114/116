# v2.59（战役铭牌与编队轨道）

## 版本分配依据

v2.58 是当前 `origin/main` 的视觉可读性基线，最新闭环 commit 为 `615b7eb`。本轮继续同一六角格战争界面阶段，针对 EasyTech/《将军的荣耀3》常见的战役作战台信息组织做增量重构。

## 背景与目标

顶部战区带需要在一眼内同时表达目标推进、指令点和当前阵营；底部编队/据点轨道需要成为稳定的地图导航基座。增加目标进度条和 CP 读数，略微提高底部跳转轨道高度与承载感，保持地图占主导。

## 非目标

不修改 GameState、GameModels、AI、战斗、移动、据点计算、六角几何、命中区域、命令 action 或规则测试。

## 实现与关键文件

- `BattlefieldChrome.swift`：战区 ribbon 增加 OBJ 进度和 CP 信息；底部 ObjectiveJumpDock 提高视觉承载高度。
- `md/flow/flow.md`、`md/flow/flowchart.md`、`WW2Tactics/README.md`、`md/test/test.md`、`md/prompt/README.md`、`update_log.md`：同步表现层事实。

## 验证与验收

本地只运行 `git diff --check`。提交到 `main` 后由 GitHub Actions 运行 static checks、Rules smoke、Xcode build-for-testing、regular screenshot 并上传 manifest、JUnit、日志和 PNG。Agent C 下载 artifact，核对最新 origin/main commitSha、runId、runAttempt 和截图。

## 风险和禁止项

不新增依赖、图片、网络请求或本地测试；不删除用户现有未跟踪的 v2.56 prompt；不得让 View 复制规则。
