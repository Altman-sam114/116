# v2.34 紧凑交战战果铭牌

## 版本号与分配依据

- 版本号：`v2.34`
- 分配依据：v2.33 已由 `origin/main` commit `268483366c5d72367a6cbe98269eb1f5e0dc171b`、GitHub Actions run `30209317453`、attempt `1` 和 artifact `ww2tactics-ci-v2.33-main-2684833-run30209317453-attempt1` 完成云端验收。实看 2064x2752 PNG 后，雪地针叶树、坦克舱口/炮口、道路、山体、河流、单位底座和三段定位轨道均正常；当前最高优先级视觉问题是两层 HIT/RET 黑色数值牌遮住交战双方和六角格关系，因此递增 v2 小版本收敛交战反馈。

## 背景

官方 EasyTech《Glory of Generals 3》截图以军械模型和地图关系为第一视觉信号，战斗数字贴近目标但不形成大面积浮层。v2.33 云端 steady-state 截图中的 HIT/RET 牌使用上下两行粗体和高对比黑底，信息完整但体积接近单位主体，交战中心又叠加结论胶囊，导致模型、状态条和交战轴线被压住。

## 目标

1. 将 HIT/RET 从双行大牌重构为单行紧凑金属铭牌。
2. 单行同时保留类型、伤害、双方 HP 前后变化，并用不同系统图标辅助区分主攻击和反击。
3. 缩小交火/压制/击毁结论胶囊，使交战双方模型、HP 状态和六角格关系更清楚。
4. 保留原有命中、伤害、反击、结论、退场 phase、steady-state 和 Reduce Motion 行为。
5. 整层继续只暴露一条完整 VoiceOver 摘要，所有装饰铭牌不重复朗读。

## 非目标

- 不修改 `GameState.swift`、`GameModels.swift`、伤害数值、反击条件、攻击结算或战役数据。
- 不修改 tile frame、坐标、zIndex、命中、手势、滚动范围、动作 HUD 或 AL/OBJ/AX 轨道。
- 不新增图片、第三方库、网络依赖、规则状态或 View 中的伤害计算。
- 不修改 workflow、CI 截图参数或 Xcode project。

## 当前架构依据

- `CombatResolutionOverlay` 继续以 `latestCombatResult` 的 `CombatResultSummary` 为唯一事实源。
- `CombatDamagePlate` 只负责展示调用方传入的真实 title、HP 文本、颜色和图标，不拥有业务状态。
- `.task(id: summary.id)`、`CombatResolutionPhase`、Reduce Motion 和 steady-state 链已完成验证，本轮保持不变。
- 整个 overlay 已关闭 hit testing，并由父视图提供唯一组合无障碍摘要。

## 实现步骤

1. 为 `CombatDamagePlate` 增加系统图标参数，主攻击使用冲击图标，反击使用回转箭头。
2. 将 VStack 两行布局改为固定单行 HStack：图标、HIT/RET 伤害、细分隔线、HP 前后。
3. 使用更小的圆角、padding、描边和阴影，保留金属深色底但降低黑牌体积。
4. 将铭牌略向单位靠近，并缩小结论胶囊字体与内边距。
5. 修复同文件 `WavingFlagShape` 声明的遗留排版，不改变旗帜路径。
6. 同步 README、flow、flowchart、test、prompt README 和 update_log。
