# WW2Tactics — 二战六角战棋

原生 SwiftUI iOS 回合制战棋原型。v3.0 将旧版卡片式战区界面重构为地图优先的战争沙盘：连续地貌、原创 3/4 俯视军械、六角战术叠层与贴边指挥控件。视觉参考来自百度检索《将军的荣耀3》的公开游戏画面；不包含 EasyTech 图片、模型、商标、肖像或第三方库。

## 战场

- 阿登 22×14 大地图，14 个据点；另有诺曼底突破战役。
- 尖顶六角格正确密铺，完整地图边界包含全部行偏移与边缘地格；绘制、点击、焦点、战果和缩放使用同一坐标。
- 原生 Canvas 连续绘制橄榄绿地表、农田、针叶树林、山脊、雪地、街区、道路和河道；不再为每格堆叠重复地形徽章。
- 坦克、火炮、步兵组和轮式侦察车使用原创俯视几何兵模；AL 蓝色实线 / AX 红色虚线环及字码共同识别阵营，不只依靠颜色。
- 五段 HP 与独立移动/攻击槽区分四种行动状态；将领、军衔、断补给和战术状态保留。双资源都耗尽才为 spent。

## 操作

1. 顶部战役名打开战役菜单；资源带显示回合、目标进度和指令点，右端明确显示“结束回合”。宽屏另显示阵营与待命数。
2. 双轴拖动地图；右上放大镜选择战役/战术/细节缩放，重开按钮重新开始当前战役。
3. 点击友军选择，点击地格/敌军获得现有移动、攻击、接敌预览；鼠标主键预览、次键执行的原链路保留。动作坞“执行”同样调用规则状态机，不存在 UI 简化规则。
4. 选中单位后，底缘单一动作坞显示名称、HP、移动/攻击状态、待命防御与攻击/接敌/据点定位。可执行预览显示真实伤害/反击或移动成本；详细战斗预测在情报中查看。
5. 底缘“编队 / 据点”展开 AL/OBJ/AX 全量横向定位轨道：友军选择、敌军/据点聚焦，不误执行行动。“下一支”选择下一支仍可行动的部队。
6. “战术支援”按需展开编队摘要、战术命令、增援部署与图例；右侧望远镜展开完整战场情报。默认收起，不永久挤小地图。
7. 战况条显示当前操作反馈，情报保留战报、战线态势、据点压力、敌情反制、后勤结果与 AI 行动回放。普通战斗在原交战位置显示真实 HIT/RET、HP 前后与结论，随后淡出但保留规则结果。

## 保留的规则

地形成本与兵种适性、六邻接、控制区、路线预览、攻击射程、兵种克制、夹击、反击、待命防御、将领与相邻协同、机动追击、炮兵弹幕/突破、士气、经验晋升、补给/断补给、据点奖励与休整、指令点、增援部署/整补、目标推进、期限与三星评价、轴心 AI、战线态势与敌方意图反制均继续由 `GameState` 管理。

v3.0 的批量地图提示只共享一次移动路线搜索，并与单格入口逐格等价测试；没有改变寻路、伤害或 AI 公式，没有跨回合缓存。

## 工程

Xcode 工程：`WW2Tactics.xcodeproj`；共享 scheme：`WW2Tactics`；iOS 17+，支持 iPad/iPhone。`ContentView` 只做根编排；静态地形、地图交互、兵模、战果、指挥控件与原有情报面板拆为独立源文件。

本轮人工要求：不做本地编译、测试、模拟器或截图，全部由 `main` 推送后的 GitHub Actions 执行。本机将来获准运行时只能使用 UDID 以 `FAC4325D` 开头的唯一模拟器，云端不受该限制。

## 云端验证

`WW2Tactics CI Results` 执行：静态检查、规则 smoke、Xcode build-for-testing、全部真实 XCTest，以及同一 SHA 的四张 PNG：iPad/iPhone 各默认态与真实 `selected-combat-impact-steady` 战果态。默认态无预置战斗；战果态由公开操作生成，不写假伤害。

每图检查尺寸、≥500 KB、战场区域亮度/可读比例，并记录 device/runtime/UDID、场景与 SHA-256。结果包包含 manifest、failure summary、独立阶段/实际 XCTest JUnit、日志、build/test xcresult 和四图；最终仍需逐图视觉检查。

当前交付状态以最新 Actions artifact 验收为准，不能把 build-for-testing 当作 XCTest 已执行，不能把历史 regular-only 截图当四图证据。测试规范见 `../md/test/test.md`，核心流程见 `../md/flow/flow.md`，历史见 `../update_log.md`。

## 已知边界

兵模是原创原生矢量绘制，不是商业游戏贴图或真实 3D 引擎。尚无专用 UI 自动化 target，四图与规则 XCTest 不证明触屏拖动、鼠标、VoiceOver、全部 Dynamic Type、横屏或全部缩放状态已实测；这些没有运行证据时仅作源码审查。长期仍需提升美术细节、触控自动化、更多战役与存档，但本轮不擅自扩展玩法范围。
