# WW2Tactics — 二战六角战棋

原生 SwiftUI iOS 回合制战棋原型。v3.3 将界面重构为全幅六角战场与贴边军用指挥牌：地图铺到屏幕边缘，独立战役/资源铭牌、右下回合按钮、单一单位动作坞和按需抽屉不再围成一张管理看板。2026-10-28 本轮已用百度搜索“将军的荣耀3”，实际打开“不列颠战役”1536×864 战场图，对照连续地貌、具象军械、低对比网格与边缘 HUD；只参考视觉语言，不保存或打包商业素材。官方来源：<https://apps.apple.com/us/app/glory-of-generals-3-ww2/id1535759278>。不包含 EasyTech 图片、模型、商标、肖像或第三方库。

## 前线视觉与界面

战场默认进入近距离“战术”视图；镜头按设备短边保持兵模可读，仍可切换战役/细节。地表增加确定性耕地、林地接壤、村镇地基和更清楚的河岸/道路，使用新增原创山林村镇 atlas。兵模放大并对置双方朝向，圆形兵种章、分段血条、AL/AX 字码和独立移动/攻击槽共同表示状态；没有改变六角输入或任何战斗规则。

边缘控件使用铆接金属牌、紧凑战役资源栏和圆形回合表。选兵指令板在短横屏横向排布；情报统一为尺寸受视口约束、带遮罩和关闭入口的右缘面板。环境战术文字只在选中/焦点处展开，显式 AI 复盘仍显示对应标记，完整细节保留在情报中。原创资产、参考来源与生成提示词见 [前线美术记录](../md/art/frontline-rebuild.md)。

## 战场

- 阿登 22×14 大地图，14 个据点；另有诺曼底突破战役。
- 尖顶六角格正确密铺，完整地图边界包含全部行偏移与边缘地格；绘制、点击、焦点、战果和缩放使用同一坐标；真实已缩放地格 Layout 提供滚动锚框，交战相关焦点取双方中点，避免窄屏裁掉一方战果。
- 原生 Canvas 组合降噪草土、低频地表起伏、耕地田块和八款山林/村镇资源；森林有针叶/混交疏林三种剪影，村镇和树林按坐标稳定变换大小、偏移与朝向。相邻雪格合成连续雪带，不用一格一个白圆斑。河流共享端点、宽度与切线；两侧真实河流夹住的城镇/道路保持水道连续，河源有自然端潭。
- 城镇接入真实相邻道路；每条真实成对道路只画一条确定性曲线，端点固定在城镇、路口或桥梁，不因缩放漂移。只有河流格相对两岸均有公路/城镇时才画桥面、护栏与桥墩。桥梁仅为表现，不改变 river 成本、不新增免费通道。
- 八款通用盟/轴兵模之外，M10、M7、虎式与豹式有四款原创专属外观；M10 显示履带式歼击车而非轮式侦察车，但保留原 recon 规则。AL 蓝色实线 / AX 红色虚线环及字码共同识别阵营，不只依靠颜色；将领徽章显示姓名首字。
- 五段 HP 与独立移动/攻击槽区分四种行动状态；将领使用带姓名首字的星徽，军衔、断补给和战术状态保留。双资源都耗尽才为 spent。可移动区域保留蓝色范围，但仅焦点/路线终点显示移动文字牌；攻击预览只突出当前攻击对象。

## 操作

1. 左上战役铭牌打开战役菜单；独立资源牌显示目标进度和指令点，宽屏增加待命数。右下金色回合按钮同时显示当前/期限回合与“结束回合”，不再占用整条顶部栏。
2. 开局与重开默认把镜头放在真实存活双方距离最近的前线中点，不篡改规则焦点或单位状态。双轴拖动地图；右上放大镜选择战役/战术/细节缩放，重开按钮重新开始当前战役。
3. 点击友军选择，点击地格/敌军获得现有移动、攻击、接敌预览；鼠标主键预览、次键执行的原链路保留。动作坞“执行”同样调用规则状态机，不存在 UI 简化规则。
4. 选中单位后，底缘单一动作坞显示名称、HP、移动/攻击状态、待命防御与攻击/接敌/据点定位；行动全部耗尽时以短说明替代三颗无用的禁用按钮。可执行预览显示真实伤害/反击或移动成本；详细战斗预测在情报中查看。
5. 左下编队图标展开 AL/OBJ/AX 全量横向定位轨道：友军选择、敌军/据点聚焦，不误执行行动。前进图标选择下一支仍可行动的部队；所有图标保留明确无障碍标签。
6. 左下支援图标按需展开编队摘要、战术命令、增援部署与图例；编队/支援互斥，均有关闭入口。右侧望远镜展开完整战场情报，面板标题栏可关闭。默认收起，不永久挤小地图。
7. 战况条显示当前操作反馈，情报保留战报、战线态势、据点压力、敌情反制、后勤结果与 AI 行动回放。普通战斗在原交战位置显示真实 HIT/RET、HP 前后与结论，随后淡出但保留规则结果。
8. 右上地图按钮开关“战区总览”（宽屏默认展开、窄屏默认收起）；AL 圆点、AX 菱形和据点方框表示真实战区。点按真实六角格只聚焦，不执行行动；空白和格外区域不误跳转。底部准星只把镜头送回前线，不改变选择。白框表示规则焦点，不冒充视口框。
9. 横屏高度不足 500pt 时用短顶栏/紧凑动作坞，总览不因宽度大而自动展开。游戏隐藏系统状态栏与非必要系统覆盖，保留安全区和所有操作入口；横屏仍是同一套地图和规则，不是截图缩放。

## 保留的规则

地形成本与兵种适性、六邻接、控制区、路线预览、攻击射程、兵种克制、夹击、反击、待命防御、将领与相邻协同、机动追击、炮兵弹幕/突破、士气、经验晋升、补给/断补给、据点奖励与休整、指令点、增援部署/整补、目标推进、期限与三星评价、轴心 AI、战线态势与敌方意图反制均继续由 `GameState` 管理。AI 复盘摘要中的关键事件先列占点，再按原有战果分数和事件序号排列；这不改变实际 AI 行动或时间线顺序。

v3.0 的批量地图提示只共享一次移动路线搜索，并与单格入口逐格等价测试；寻路进一步在单次只读查询中快照地格/存活单位/ZOC，保留 FIFO 与 tie-break，并由独立旧搜索逐路线对比；没有改变寻路、伤害或 AI 语义，没有跨回合缓存。

## 工程

Xcode 工程：`WW2Tactics.xcodeproj`；共享 scheme：`WW2Tactics`；iOS 17+，支持 iPad/iPhone。`ContentView` 只做根编排；导航投影、河岸几何、道路/桥梁计划、确定性地貌布局、静态地形、地图交互、兵模与战果各自独立。战役栏、单位动作坞与地图编排分离；原 5,044 行情报文件按七个领域拆分，保留规则入口。七个原创 PNG 随包离线使用，20 个 sprite 由 ImageIO 一次解码/裁格并复用，预算仍为 24 MB，不引入第三方库或复杂资产管线；完整提示词与来源见 `../md/art/v3.0-artwork.md`、`../md/art/v3.2-artwork.md`。

本轮人工要求：不做本地编译、测试、模拟器或截图，全部由 `main` 推送后的 GitHub Actions 执行。本机将来获准运行时只能使用 UDID 以 `FAC4325D` 开头的唯一模拟器，云端不受该限制。

## 已知边界

兵模与地貌是原创透明预渲染资源，不是商业游戏贴图或实时 3D 引擎；四款命名装备之外仍用通用模型。VisualUITests 的设计范围为旋转、战果画面、情报开合和动作坞移动/回合链，是否实测通过以最新结果包为准；不证明逐格直接触屏、鼠标、拖动、VoiceOver、全部字号或全部缩放。Vision 只识别已知系统通知，不代替人工检查。长期仍需提升美术、更多战役与存档，本轮不擅自扩展玩法。
